# Reasoning Layer

## Overview

Recommended recipes and mechanistic explanations are generated by the fine-tuned RLM. 

Key Atomic Skills:
- **Scientific Report Generation**: Automatically generates complete scientific analysis reports from experimental data
- **Mechanistic Reasoning**: Infers physical-chemical mechanisms of material behavior from data patterns
- **Structure-Activity Relationship Analysis**: Establishes correlations between material composition, structure, and properties
- **Database Integration**: Directly reads experimental records from database and generates structured text

## Layer Structure with Atomic Skills

```
Reasoning/
├── data/
│   
└── src/
```

## Database Requirements

Requires access to the master experimental records table containing material composition, synthesis protocols, characterization data, device performance, and other fields.

## Basic Usage

### Environment Setup

```bash
conda activate rlm_agent
cd seven_layers/Reasoning
```

### Usage Example

```python
from src.perovskite_report_generator import PerovskiteReportGenerator

# Initialize generator
generator = PerovskiteReportGenerator()

# Load single experimental record from database and generate report
report = generator.generate_report(
    record_id="exp_20250101_001",
    report_type="full_scientific"
)

# Save report
generator.save_report(report, output_path="reports/report_001.json")
```

### Batch Generation

```python
record_ids = ["exp_001", "exp_002", "exp_003"]
reports = []

for rid in record_ids:
    try:
        report = generator.generate_report(record_id=rid)
        reports.append(report)
    except Exception as e:
        print(f"Failed to generate report for {rid}: {e}")

generator.save_batch(reports, output_dir="reports/batch_20250101/")
```

### Database Text Conversion

```python
from src.totext_db import get_random_row_from_db, row_to_text

# Get random sample for few-shot learning
sample_row = get_random_row_from_db(limit=1)

# Convert to natural language description
text_description = row_to_text(sample_row)
```

### Key Modules for Executing Task

- **perovskite_report_generator.py**: Report generation for recommended recipes.
- **prompts.py**: Prompt template management for report generation. 
- **totext_db.py**: Natural-language conversion for database records.
